Frequently Asked Questions

Does The Usual Suspects collect or transmit any user data?

No. The Usual Suspects executes 100% locally in the client browser. No telemetry, cookies, analytics, or external API queries are executed. Voice recognition uses the browser's built-in Web Speech API.

How does the 1-Click Auto-Fix remediate violations?

The Auto-Fix engine dynamically traverses the active DOM to generate descriptive fallback alt tags for images, injects accessible labels for input fields, removes pinch-to-zoom viewport restrictions, and establishes primary landmarks and language specifications.

What makes the Dyslexia Typography Engine unique?

Unlike solutions that merely use standard fonts, The Usual Suspects integrates genuine OpenDyslexic vector fonts with heavy-bottom baselines that anchor letters against flipping or rotation, paired with custom letter, word, and line spacing.

What is the bonus compliance report?

The Usual Suspects generates an official, printable WCAG 2.1 Level AA Compliance Certificate (PDF/HTML) complete with grade certification, timestamp, domain verification, and pass/fail checklist for small businesses and regulatory audits.
