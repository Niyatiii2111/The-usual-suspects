# The Usual Suspects - Showcase & Landing Portal
### Track 3: Universal Web Accessibility Layer for Any Website (The Usual Suspects)

This is the official companion landing portal and interactive showcase for **The Usual Suspects**.

## ✨ What's Included
1. **Interactive Accessibility Playground**: Live in-browser demonstrations of OpenDyslexic typography, Bionic Reading, Reading Ruler guide, glowing focus rings, VIBGYOR contrast themes, Speech Synthesis, and Voice Commands.
2. **Real-Time WCAG 2.1 AA Audit Scanner & 1-Click Auto-Fix**: Scans the live DOM across 5 core categories, remediates violations in 1 click, and exports the official client-ready Compliance Certificate.
3. **Chrome Extension Hub**: Direct download of `the-usual-suspects-extension-v2.1.zip` (Manifest V3) with 3-step setup guide and keyboard hotkeys cheat-sheet.
4. **Website Owner Embed Generator**: Live customizable 1-line script embed with toggle to test `widget.js` directly on this page.
5. **Live Integration Link**: Direct link to the public portal case study (`demo-site.html`).

## 🚀 Running Locally
Open `index.html` directly in any web browser or serve with a static server:
```bash
npx serve .
```
